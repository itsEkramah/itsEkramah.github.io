## About this repository

This repository contains the website's source code and content. It is built with Astro and Markdown/MDX, and hosted on GitHub Pages.

You can browse the website directly; no installation or setup is needed.

## Publish an article

Follow [the publishing guide](docs/PUBLISHING.md) to add your writing through GitHub or VS Code. Articles are Markdown files in `src/content/articles/`; publishing updates the homepage, archive, RSS and sitemap automatically. Only owner-written or owner-supplied articles should be added.
