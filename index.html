Predicting antimicrobial resistance in N. gonorrhoeae

2025–2026

Bioinformatics Computing II · Genomic machine learning

Tools: Python, Pandas, scikit-learn, Jupyter

In my Bioinformatics Computing II project, I used genomic unitig features from Neisseria gonorrhoeae isolates to study resistance to azithromycin and ciprofloxacin. I compared machine learning models and examined how different evaluation choices affected their performance.

  • Reviewed 3,786 metadata records and matched labelled isolates with antibiotic-specific genomic features.
  • Compared logistic regression and random forest models using a prevalence baseline and grouped five-fold cross-validation.
  • Used bootstrap confidence intervals and geographic subgroup comparisons to examine variation in model performance.
  • Used BLAST to examine selected unitigs, including alignments to resistance-associated gene regions involving penA and gyrA.

The models performed well in internal cross-validation, although the results may be optimistic because the genomic features had already been filtered using GWAS. Testing on independent datasets would help establish how well the models generalise.

Methods, results & figure

Variance filtering and chi-square feature selection are fitted inside each training fold. Identical unitig profiles stay in the same fold. I did not train a prediction model for cefixime because only five isolates were labelled resistant.

RNA-seq analysis of Notch2 knockout stem cells

2025–2026

Genomics · Mouse hippocampal neural stem cells

Tools: Python, PyDESeq2, R, DESeq2, Bash

I analysed the publicly available GSE116773 dataset to compare gene expression between Notch2 conditional-knockout and wild-type mouse hippocampal neural stem cells.

  • Combined 24 technical count files into six biological RNA preparations, with three samples per condition.
  • Used PyDESeq2 for differential expression analysis and identified 121 genes with an adjusted p-value below 0.05.
  • Used PCA, sample-distance heatmaps and gene expression plots to explore differences between samples.

One of the wild-type samples, WT3, differed noticeably from the others. This was an important consideration when interpreting the differential expression results, especially with only three biological samples per condition.

GitHub Analysis code GEO dataset
Methods, results & figure

I used the study-provided GRCm38 count data and performed differential expression analysis with PyDESeq2, Wald tests and Benjamini–Hochberg correction. Of 21,531 retained genes, 77 had higher and 44 had lower expression in knockout at FDR < 0.05. None of the eight predefined candidate genes, including Id4, passed that threshold.

Differential expression does not by itself establish direct regulation by Notch2. The repository also contains GRCm39 read-processing scripts, but their original count matrix is unavailable. The results shown here use the GRCm38 count data.

PathoScope AI

Mar–Aug 2026

Functional Genomics · Team software project

Tools: Python, FastAPI, PostgreSQL, NCBI E-Utilities; team interface in Next.js

PathoScope AI was a team project for our Functional Genomics course. We developed a web-based prototype that brings together tools for viral sequence analysis and gene expression workflows. I mainly worked on the backend, including pipeline execution, FASTQ integration and PubMed retrieval.

  • Worked on pipeline execution, job-status tracking and database connectivity.
  • Helped integrate read-processing tools, literature searches and report generation into the application.

PathoScope AI was developed as a course project and remains a software prototype. Some fallback functions use simulated annotations or substitute a reference sequence when external tools are unavailable.

GitHub repository Pipeline runner Watch project demo ↗
More about the project

The team implementation includes six-frame ORF scanning and wrappers for FastQC, fastp, SPAdes, DIAMOND and HMMER. It also includes an exploratory expression analysis module using log-CPM, Welch's tests and Benjamini–Hochberg correction.

The prototype has not been containerised. AI-generated literature summaries still require human review.
