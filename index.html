01

Genomic prediction · Python

Antimicrobial resistance in N. gonorrhoeae

Bioinformatics Computing II · 2025 coursework; revised analysis, 2026

Can binary genomic unitigs distinguish resistant from susceptible isolates without letting duplicate profiles cross the training–test boundary?

Methods

The revised notebook audits 3,786 metadata records and compares class-weighted logistic regression and random forest against a prevalence baseline. It uses five-fold cross-validation grouped by identical unitig profiles, with variance filtering and chi-square feature selection inside each training fold.

02

Transcriptomics · Python / R

Notch2 knockout and hippocampal stem-cell expression

Genomics · 2025 coursework; public-count reanalysis, 2026

Which measured genes differ between Notch2 conditional-knockout and wild-type hippocampal stem-cell RNA samples?

Methods

The current GSE116773 reanalysis aggregates 24 technical files into six biological RNA preparations, three per condition. PyDESeq2 fits a negative-binomial model with Wald tests and Benjamini–Hochberg correction. Sample checks include blind variance-stabilised PCA and sample distances.

Recorded count-level result

121 genes at FDR < 0.05 among 21,531 retained genes: 77 higher and 44 lower in knockout. None of the eight predefined candidate genes passes genome-wide FDR, including Id4.

This is an association analysis of six pooled RNA preparations. WT3 separates from the other samples; the small sample size and sample structure limit inference. Expression changes do not establish direct regulation by Notch2.

Available evidence: public count archive, sample mapping, analysis scripts, result tables, figures and checks. The earlier HISAT2/featureCounts/DESeq2 workflow is preserved separately; missing original counts prevent reproduction of its historical results.

03

Team software prototype · FastAPI / Next.js

PathoScope AI

Functional Genomics · March–August 2026

A collaborative prototype connecting viral-sequence and expression-analysis workflows with a browser interface.

My contribution

The project contribution notes identify my focus as the pipeline runner, FASTQ processing integration, PubMed literature retrieval, AI-assisted reporting and database connectivity. These are team-project contributions, not a claim of sole authorship.

Implemented scope

The code includes sequential job orchestration, status tracking, NCBI E-Utilities retrieval and caching, external-tool wrappers, six-frame ORF scanning, and an exploratory log-CPM / Welch-test expression module with BH correction.

Prototype boundary: some external-tool failures trigger simulated annotations or reference-sequence substitution. Those outputs do not verify assembly or alignment. Docker deployment is future work; the repository does not establish production readiness or hallucination-free interpretation.
