Predicting antimicrobial resistance in N. gonorrhoeae

2025–2026

Bioinformatics Computing II · Genomic machine learning

Tools: Python, Pandas, scikit-learn, Jupyter

I used binary genomic unitigs to study resistance to azithromycin and ciprofloxacin, with a focus on class imbalance and how evaluation choices affect the result.

  • Audited 3,786 metadata records and matched isolates to antibiotic-specific genomic features.
  • Compared logistic regression and random forest with a prevalence baseline, using five-fold cross-validation grouped by identical genomic profiles.
  • Examined uncertainty with bootstrap intervals and compared performance across geographic subgroups.

Key lesson: strong overall prediction can hide differences between populations. The supplied features were already GWAS-filtered, so the internal scores still need independent validation.

Methods, results & figure

Variance filtering and chi-square feature selection are fitted inside each training fold. Identical unitig profiles stay in the same fold. Cefixime is included only in the data audit because it has five resistant isolates.

RNA-seq analysis of Notch2 knockout stem cells

2025–2026

Genomics · Mouse hippocampal neural stem cells

Tools: Python, PyDESeq2, R, DESeq2, Bash

I analysed public GSE116773 data to compare gene expression between Notch2 conditional-knockout and wild-type samples.

  • Combined 24 technical count files into six biological RNA preparations: three per condition.
  • Used negative-binomial modelling and multiple-testing correction; the count-level analysis identified 121 genes at FDR < 0.05.
  • Explored sample structure with PCA, sample distances and gene-level expression plots.

Key lesson: sequencing files are not independent biological replicates. Sample structure matters: WT3 differs from the other samples, which calls for care when interpreting the expression results.

GitHubAnalysis codeGEO dataset
Methods, results & figure

The current analysis starts from study-provided GRCm38 counts and uses PyDESeq2, Wald tests and Benjamini–Hochberg correction. Of 21,531 retained genes, 77 had higher and 44 had lower expression in knockout at FDR < 0.05. None of the eight predefined candidate genes, including Id4, passed that threshold.

These are expression associations in six pooled RNA preparations, not evidence of direct regulation by Notch2. The earlier GRCm39 read-processing scripts are retained separately; their original count matrix is unavailable.

PathoScope AI

Mar–Aug 2026

Functional Genomics · Team software project

Tools: Python, FastAPI, PostgreSQL, NCBI E-Utilities; team interface in Next.js

I contributed to a prototype that brings viral-sequence and expression-analysis workflows into a browser interface. My work focused on workflow orchestration, FASTQ integration, PubMed retrieval and AI-assisted reporting.

  • Worked on sequential workflow execution, job-status tracking and database connectivity.
  • Integrated read-processing tools and literature retrieval with caching to support the analysis workflow.

Project scope: a teaching and development prototype. External-tool fallbacks can produce simulated annotations or substitute a reference sequence, so those paths do not establish biological results.
