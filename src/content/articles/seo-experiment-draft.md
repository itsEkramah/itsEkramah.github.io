This is an unpublished experiment plan. No traffic, indexing, ranking or AI-citation result is claimed.

## Define the observation

Before making a change, record the page, query set, date range, country, device and available baseline measurements. Identify other changes that could affect the same period.

## Document the intervention

Describe the exact technical change and keep a dated record. A local HTML report can document markup; it cannot establish search visibility.

## Work to complete

Add permissioned observations, primary documentation and an explanation of uncertainty. Distinguish correlation from causal impact. Keep this outline unpublished until real measurements support the final text.
